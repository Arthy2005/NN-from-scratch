# Neural Network from Scratch 

## Overview
This project implements a fully connected neural network from scratch using Python and NumPy, without relying on deep learning frameworks.

## Objective
- Understand forward propagation and backpropagation
- Implement gradient descent manually
- Build intuition behind neural network training

## Methodology
- Custom implementation of neurons and layers
- Activation functions (Sigmoid, ReLU)
- Loss function computation
- Backpropagation for weight updates
- Training using gradient descent

## Results
Experiments conducted on sample datasets.  
Performance metrics and plots will be refined.

## Project Structure
- `notebooks/` : Core implementation and experiments
- `src/` : Planned modular code structure

## Tech Stack
- Python
- NumPy
- Matplotlib
